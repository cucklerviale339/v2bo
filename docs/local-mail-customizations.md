# 本地邮件定制与升级

邮件消息统一通过 `internal/platform/mailwire` 构建，中文主题和发件人名称使用 MIME 编码，正文使用 quoted-printable。HTML 邮件同时包含纯文本和 HTML 两部分。

管理员群发支持模板变量 `content_html`：管理员输入的 HTML 原样保留，纯文本转义并保留换行。普通通知的 `content_html` 始终由转义后的正文生成。已有模板的 `content` 变量和渲染方式保持兼容；模板未使用 `content_html` 时不会自动改变行为。

站点品牌从现有配置读取。自定义模板可继续放在 `resources/views/mail/<模板名>/`，由 `email_template` 配置选择，无需为每个站点维护独立代码分支。本地专用模板不要与仓库已有模板重名，也不要把运行配置、凭据或邮件任务数据提交到仓库。

升级使用 `git pull --ff-only`。本地修改了受 Git 管理的源码且上游修改同一文件时，Git 会拒绝更新，即使双方修改位于不同函数。通用修复应合入主分支，自定义品牌保留在配置与独立模板目录中。不要通过强制重置或自动覆盖本地修改来绕过检查。
