## 订阅中心

菜单位于“内鬼管理”下面。入口合并为四个标签，后端接口与历史记录继续兼容：

| 标签 | 数据与操作 |
| --- | --- |
| 订阅统计 | 成功获取订阅的记录、用户 ID/邮箱及 UA 查询、当日低流量、连续 N 天每天低流量明细 |
| 请求与拦截记录 | 全部订阅请求的放行、业务失败、规则命中和实际拦截，用户详情与快捷规则 |
| 爬虫 UA 用户 | 脚本/爬虫类别触发用户及明细，白名单命中也可记录 |
| 防护设置 | UA/IP 白黑名单、Token 黑名单、频率限制、空 UA 与爬虫 UA 拦截开关 |

成功订阅统计与全部请求统计不相加；两者口径与保留期不同。关闭防护仍记录请求，爬虫 UA 默认只记录；实际拦截需要防护模式为“正式拦截”，并开启对应开关。升级不会重置已有防护设置。

旧地址 `/subscribe-access` 打开订阅中心的统计标签，`/config/subscribe-guard` 打开防护设置。标签切换保留未保存配置。

## 域名解析

支持 DNSPod 国际版 Token API，以及 DNSPod 中国版/国际版腾讯云 API 3.0。可查询域名与记录、添加/修改/删除记录、启用/停用记录，并设置线路、TTL、MX、权重等服务商支持的字段。

在“域名解析 → 账号设置”配置凭证，可先验证账号。凭证保存在 `config/admin.json`，Linux 下文件权限为 `0600`，配置采用原子替换和进程内互斥，避免与系统配置并发保存时互相覆盖。状态接口只返回掩码；DNS 管理接口需要管理员登录，并禁止缓存响应。环境变量覆盖凭证时页面会提示。

## 备用监控

1. 在“探针”标签设置 HTTPS 接入地址，如 `https://probe.example.com`，该地址需转发到当前 Go 服务。
2. 创建探针，在需要观察连通性的 Linux 服务器上执行页面生成的安装命令。支持 amd64/arm64，下载校验 SHA256，密钥配置权限为 `0600`。探针通过专用 Bearer Token 鉴权，撤销后立即拒绝上报。
3. 新建规则并选择 DNSPod 域名、已有 A/AAAA/CNAME 记录和探针。按优先级填写主备目标与 TCP 探测端口。首个启用目标应与当前 DNS 解析一致。
4. 核对配置后显式启用规则。新规则默认停用，自动回切默认关闭；启用后才能开始该规则的探测。至少三批有效上报完成预热，过期结果不参与决策。
5. 在“监控详情、诊断日志、事件”中查看探针状态、连续失败/成功次数、切换与重试原因。可手动切换，也可单独启用恢复后回切。

多探针按阈值共同判断，只有单个可用探针时采用更高阈值。所有探针离线、数据不足、探针意见不一致或没有健康备用目标时不会盲目切换；冷却期限制反复切换。修改 DNS 与数据库状态通过持久任务、锁、重试和补偿协调。重新启用探针会清除旧结果并重新预热。

诊断日志、探针上报去重记录及已通知事件保留三天，每小时分批清理；待通知事件保留重试。清理任务独立运行，不改变原订阅和流量记录的保留策略。

Telegram 使用现有机器人设置和已绑定的管理员；发送失败保留事件等待重试。通知采用至少一次投递，发送成功但回写数据库失败时可能重复通知。未配置机器人或没有接收人不会标记为已送达。DNSPod凭证、探针Token均应按服务器配置密钥保护；探针Token为了再次生成安装命令会以明文保存在数据库，仅管理员接口可读取。

## 老项目升级

新增表均为 `v2_dns_*`，按需重复执行初始化，不改用户、订阅 Token、套餐、流量及既有地址规则。初始化失败记录错误并由后台重试，原订阅服务继续启动。没有创建并启用规则时，不会改 DNS。

正常更新仍使用 `./scripts/appctl update`。它会额外构建 `storage/probe/forest-probe-linux-amd64`、`forest-probe-linux-arm64` 及校验文件；也可单独执行 `./scripts/appctl build-probe`。该目录不入 Git。前端构建产物随本次代码一同更新。

可选环境变量：

| 变量 | 用途 |
| --- | --- |
| `PROBE_STORAGE_DIR` | 探针下载文件目录，默认 `../storage/probe`，相对 Go 服务工作目录 |
| `PROBE_TRUSTED_PROXY_CIDRS` | 允许读取转发 IP 的代理网段。默认含回环与私网段；部署时应收紧到实际代理，如 `127.0.0.0/8,::1/128` |

升级前保留数据库、`.env.go` 和 `config/admin.json` 备份。回滚前先停用 DNS 规则并等待切换任务完成；回滚代码不会撤回已生效的公网 DNS 修改。新增表可以保留，旧版不读取它们。
