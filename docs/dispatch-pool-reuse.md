# 备用池 IP 复用

备用池的“有配置引用”表示该 IP 仍出现在下发规则或活跃卧底组中。关闭的规则、当前被其他分组覆盖的原规则、为未来账号保留的 ID 范围仍属于配置引用，防止回退下发时与新分配冲突。当前人数为零不代表这些引用可以删除。

单独的入口监控记录不占用备用 IP。只要没有上述配置引用、检测端口与源入口一致，且满足原有探针在线、检测新鲜度、连续成功要求，自动二分和卧底细分都可选用该 IP；已删除、已关闭或不再下发的旧监控不会永久阻止复用。

选址保留备用池的人工排序优先级。同优先级下，先选没有旧入口监控的 IP，再选需要复用的 IP，尽量避免在多个分组之间立即往返使用同一入口；没有全新入口时，符合条件的旧 IP 仍可分配。历史下发暴露记录仍按原规则参与筛选保护，不会因新监控身份而清除。

分配在原有的下发互斥事务中执行，并再次检查配置引用。若存在旧监控，将其停用并归档为独立的历史身份，保留旧监控 ID、检测历史和分组关联；为新分配创建新监控 ID。旧绑定和实时状态被清除，旧轮次上报不会计入新分配。

新监控复制故障入口的检测端口、检测间隔、超时与启用的绑定探针，重新建立正常基线。不会沿用旧监控的 443，也不会修改节点订阅端口。备用池原来的测活结果继续用于选址，不会变成新入口的历史故障证据。

原有频率限制、同探针正常对照、故障证据和单人组限制保持有效；新监控身份不改变发起分组的根分组及限频归属。分配失败时，监控归档、新监控和规则变动一并回滚。无需升级探针或迁移数据库表结构。
